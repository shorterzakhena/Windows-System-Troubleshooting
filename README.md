## Windows-System-Troubleshooting
## Project Overview

This lab focuses on basic Windows system administration and IT troubleshooting.

The objective is to learn how to collect computer information, inspect network settings, and test network connectivity using built-in Windows tools.

## Objectives

- Identify basic Windows system information.

- Examine network configurations.

- Understand IP addresses.

- Test network connectivity.

- Practice basic IT troubleshooting commands.

## Tools & Technologies

- Windows 10 or Windows 11

- Command Prompt

- PowerShell

- Internet connection

## Step-by-Step Instructions

## Step 1: Open Command Prompt

Click the Windows Start button.

Type cmd in the search bar.

Select Command Prompt.

Keep the window open for the remaining steps.

## Step 2: Check System Information

Enter:

## systeminfo

What this does:

Displays information about your computer, including the operating system, system manufacturer, processor, and installed memory.

Screenshot 1: Save a screenshot showing your system information.

## Step 3: Check Your IP Address

Enter:

## ipconfig

What this does:

Displays your computer's basic network configuration, including its IP address.

Screenshot 2: Save a screenshot showing your IP configuration.

## Step 4: View Detailed Network Information

Enter:

## ipconfig /all

What this does:

Displays additional network information, including your network adapter, DNS servers, and default gateway.

Screenshot 3: Save a screenshot showing the network information.

## Step 5: Test Network Connectivity

Enter:

## ping google.com

What this does:

Sends test messages to a destination to check whether your computer can communicate with it.

Look for replies and response times.

Screenshot 4: Save a screenshot showing your ping results.

## Step 6: Document Your Findings

Answer these questions:

What version of Windows are you using?

What is an IP address?

What does the ipconfig command display?

What does the ping command help you troubleshoot?

Were you able to successfully reach the test destination?
